FAQ

Does runik support my e-reader?

Runik directly supports Kobo and Kindle devices, and can also export to StarDict format. If there is a device or format you'd like supported, please open an issue on github.

How do I use runik with my kindle?

For runik to support your kindle device:

  1. Install the Kindle Previewer App.
  2. In runik, navigate to the "Settings" tab and enter the full path to the kindlegen executable.

    The default paths for Windows and macOS respecetively are:
    • C:\Users\[your_username]\AppData\Local\Amazon\Kindle Previewer 3\lib\fc\bin\kindlegen
    • /Applications/Kindle Previewer 3.app/Contents/lib/fc/bin/kindlegen
Why are Kobo dictionaries generated with runik prefixed with "dicthtml-[r]"?

Kobo expects dictionaries to be in the following format "dicthtml-[language-code]", for example, a spanish dictionary called "dicthtml-es" would be displayed by the device as "Espanol". Since runik dictionaries don't follow this language code naming convention, the full dicthtml prefix is displayed. I am looking for way around this, and am hoping to have a fix for version 1.

How does runik handle spoilers?

In short, runik is okay at handling spoilers. By only using the first few sentences of a wiki article, runik dictionaries tend to mostly avoid spoilers that would be found deeper in the article, but there is no guarantee that a generated dictionary doesn't contain spoilers. The quality of a generated dictionary largely depends on the quality of the wiki. Use at your own risk.

Why does my computer warn me when I try to install runik?

Because Runik is in beta and not yet signed with a developer certificate, Windows and macOS will show a warning the first time you try to open it.

On Windows: Click More info → Run anyway when prompted.
On macOS: Right-click the app and choose Open.

I encountered a bug, where can I report it?
